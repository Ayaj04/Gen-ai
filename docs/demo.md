# FastAPIGuide demo video

[Watch or download the WebM recording](demo.webm?raw=true).

This is a recording of the running local app, not an image-generated mockup.
It shows an HTTP 404 question, the agent's approval step, the local-tool answer,
then the FastAPI Snippet card with Python source, copy action, and docs/source
links. Browsing is labeled explicitly. No Groq answer is simulated in the video.

The recording uses localhost; the deployed API is available separately at
https://gen-fast-api.onrender.com/docs. If GitHub displays a file page instead
of a player, use Download raw file and open the WebM in Chrome, Edge, or VLC.
